# POCHO LAB v0.1

現行ゲーム v0.1.6 の Matter.js 物理・behaviorRules を使う自動バランスシミュレーターです。

## 主な機能
- NONE / STICK / POP 実測率
- レイヤー別の決着率
- 速度帯・盤面密度・進行度別の反応率
- グループサイズと接着成長
- 1POP平均消滅数
- 条件ごとの「裏成立率」と実際の採用回数
- AI射出パターン切替
- STICK / POP をレイヤーごとにON/OFF
- disabled 条件の実験的再有効化
- 接触ログCSV / 集計CSV

GitHub Pagesへ置く場合は index.html / styles.css / lab.js / data.js を同じディレクトリへ置いてください。
