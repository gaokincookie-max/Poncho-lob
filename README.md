# POCHO LAB v0.8

ぽちょ本家 v0.2.1 の挙動・役バランスを検証する開発用シミュレーターです。

- 初期ぽちょ7体
- 1射=3体セット
- 3体セット解放後450msの同セット相互反応保護
- 上向き重力 0.00135
- 本家v0.2.1の挙動条件状態を同期
- NONE / STICK / POP、速度、密度、進行度、グループ成長を集計
- 70役（有効64役）の成立率・代表表示・多段得点を集計
- 人間観察モードでも3体セットを振り回して射出可能
- 危険条件から個別ON/OFF可能

`index.html` を GitHub Pages で公開して使用してください。
