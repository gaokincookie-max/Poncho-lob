# POCHO LAB v0.3

ぽちょの挙動条件を、大量自動シミュレーションとリアルタイム観察の両方で検証する開発ツールです。

## 2つの使い方

1. **大量自動シミュレーション**
   - 複数ゲームを高速実行
   - NONE / STICK / POP、速度帯、密度、グループ成長、条件別裏成立率を集計

2. **観察プレイ / HUMAN vs AI**
   - 人間操作：下部のぽちょを引っ張って離す
   - AI自動：同じ盤面で Random / Strong / Weak / Center / Crowd を切替
   - 接触ごとに採用条件と裏成立条件をリアルタイム表示
   - 観察ログCSV出力
