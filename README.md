- iPhone/Safariで「押しても何も起きない」ように見える問題を軽減
- 初期ゲーム数を50→5へ変更（動作確認後に増やしてください）
- JavaScript実行時エラーを画面のステータス欄とダイアログへ表示
- NONE / STICK / POP、条件裏成立率、速度・密度・グループ統計はv0.1から維持
